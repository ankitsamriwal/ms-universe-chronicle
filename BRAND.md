## Terms relied on

Microsoft's icon terms on the Azure architecture icons page: "Microsoft permits the use
of these icons in architectural diagrams, training materials, or documentation. You can
copy, distribute, and display the icons only for the permitted use unless granted
explicit permission by Microsoft. Microsoft reserves all other rights."

How this site complies:
- Icons are used unmodified (no cropping, flipping, rotation, distortion) and always
  next to the product name, per Microsoft's "Do's".
- Icons illustrate Microsoft's products inside an informational documentation/diagram
  context (the landscape map and per-entry tags). They are never used to represent this
  site or any other product, and never as a logo.
- The Microsoft corporate logo is NOT used anywhere.
- The site carries a visible "Unofficial - not affiliated with or endorsed by
  Microsoft" notice in the top bar and footer.

## Judgment calls and gaps (flagged)

- Microsoft's stated permitted uses are "architectural diagrams, training materials, or
  documentation". This chronicle is treated as documentation/diagram use; that reading
  is a judgment call, not an explicit license for websites.
- Microsoft 365 app icons (Teams, SharePoint, Outlook, OneDrive, Word, Excel,
  PowerPoint), the Windows logo, the GitHub mark, Microsoft Copilot, MAI, and Microsoft
  IQ have no comparably licensed free icon set. Those products use original letter
  tiles designed for this site instead.
